# 手机显示、实时调速与游船调整

- 画布不再限制为 1.5 倍像素比，采用手机真实 DPR；画布尺寸仍受 GPU 的 renderbuffer/viewport 上限保护，横竖屏变化时重新计算。
- slider 同时处理 changing 和 change，步进为 0.5 倍，范围为 0.5–3 倍；拖动回调中立即向原生画布同步速度。
- 页面改为一屏弹性布局：标题和操作面板保留完整高度，面板靠下，中间画布填满剩余空间。不再使用固定 66vh 高度或滚动容器；底部预留手机安全区，短屏压缩标题及按钮间距。
- 游船沿河中两条航线循环，在两端平滑转弯，每圈从两个方向各穿桥一次。船的垂直尺寸调整到桥面下方，保留宽度与长度。

## 验证

- 3 倍像素比测试：390×520 CSS 像素的画布输出 1170×1560 物理像素。
- HBuilderV 自动生成的页面含 changing 绑定；页面拖动回调将输入吸附到 0.5 倍档位并立即同步转速，检查通过。
- 航线采样 2000 点，确认船体始终在河道内、朝向与运动方向一致、循环位置连续、每圈穿桥两次。
- 实际模型包围盒确认船顶低于桥面底部；暂停时船和摩天轮停止，恢复后继续。
- 390×844、375×667、360×640、393×852 布局检查通过，包含 34px 底部安全区及 48px 状态栏组合：按钮、速度滑条和底部说明完整显示，无横向或纵向溢出；画布区按屏幕大小分配约 297–427px。
- 日夜同步、触摸旋转/缩放、复位、尺寸变化与释放检查通过。

上述测试使用实际页面编译产物与浏览器 WebGL 适配环境，并非手机实测帧率。重新运行到微信开发者工具后，请生成新的预览二维码，在手机里打开新版本。
